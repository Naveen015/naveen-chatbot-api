# Project: Personal AI Assistant Chatbot

**Role**: Generative AI Engineer  
**Duration**: Apr 2025 – May 2025  

---

## Overview
A high-throughput, low-latency personal AI assistant chatbot built with fine-tuned LLMs, vLLM serving, and agentic RAG.

## Key Technical Achievements (STAR Format)
* **Situation**: Deploying large language models for real-time interactive query answering consumes high GPU VRAM and can suffer from output hallucinations.
* **Task**: Fine-tune an open-weights LLM and build a low-latency RAG pipeline with sub-second response times and reduced hallucinations.
* **Action**: Fine-tuned a Mistral 7B LLM using QLoRA parameter-efficient fine-tuning and deployed inference on cloud GPUs via vLLM with PagedAttention. Built a high-throughput RAG pipeline with document embeddings, hybrid vector search, and context-window optimization.
* **Result**: Reduced GPU memory usage by 40% while preserving baseline model quality, achieved sub-second response latency, and cut hallucination rates by 78%.
